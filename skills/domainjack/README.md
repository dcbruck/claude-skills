# /domainjack

**What it does**

Finds mechanisms that already work in some other industry, science, subculture, or era and transfers them to the target you name. Three modes: give it a target and it hunts for donor domains, give it a donor domain plus a target and it bridges the two, or give it a practice you spotted and it finds where else that mechanism would land. Every idea carries a proof level and a spread score (maturity elsewhere times novelty here times transfer feasibility), with a guard against ideas that only look novel because nobody checked.

**Install**

See the root `INSTALL.md`.

**Try it**

```
/domainjack reduce no-shows for discovery calls with new prospects
/domainjack what could a consulting onboarding process borrow from air traffic control
```

**Files it uses**

- None. Web tools are optional for verifying niche sources.

**Pairs with**

- `/triage` to capture verdicts on the ideas you want to keep
- `/blindspot` for ideas found in the seams of your own system instead of borrowed from elsewhere
- `/beastmode` routes "what could X borrow from Y" prompts here
